# ABSENKU — Sistem Absensi PKL Kominfo Tanggamus

Sistem absensi online peserta didik yang sedang PKL di Kominfo Tanggamus.

## Tech Stack

- **Frontend**: Next.js 15 + TypeScript
- **Styling**: Tailwind CSS
- **Database**: Supabase (PostgreSQL)
- **Auth**: Supabase Auth + Google OAuth
- **Storage**: Supabase Storage
- **Realtime**: Supabase Realtime
- **Maps**: Leaflet.js + OpenStreetMap

## Getting Started

```bash
npm install
npm run dev
```

## Environment Variables

Salin `.env.example` menjadi `.env.local` dan isi dengan nilai yang sesuai.
